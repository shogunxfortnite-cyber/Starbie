## what is it
It's a small star shape desk tamagochi.

## BOM
Xiao Esp32 c3 

mpu6050

0.96 oled

MX switches

keycaps

10k resistor

the PCB that I made

## how to code
for coding we will be using Arduino ide.

you would need the library for it

## working 
It is controlled by 2 switches and motion with the help of the mpu6050 module.
